PROJECT NEXUS - HOW TO RUN AND TEST
====================================

The main way to play is the game board in your web browser. You can also
play in a terminal, watch bots play each other, and run the automated tests.


1. ONE-TIME SETUP
-----------------
You need Node.js 24 or newer.

  a. Open a terminal: press the Windows key, type "PowerShell", press Enter.
     (Windows Terminal or the VS Code terminal work too.)

  b. Go to the project folder (wherever you cloned it), for example:

       cd "$HOME\OneDrive\Desktop\Project_Nexus"

  c. Install the project's packages (only needed once, or after pulling
     changes that update package.json):

       npm install

  If you see "npm is not recognized", close the terminal and open a new one
  so it picks up Node.js. If it still fails, reinstall Node.js LTS from
  https://nodejs.org


2. PLAY IN YOUR BROWSER
-----------------------
  npm run dev

  Then open http://localhost:5173 in your browser. Leave the terminal open
  while you play; press Ctrl+C in it to stop the game server.

  New to Magic? Press "Learn to play" on the menu. A coach walks you
  through one turn with the Red-White Starter Kit: playing a land, casting
  an Equipment, aiming a spell, and attacking for the win. Then "Play a
  practice game" starts a fresh game against the AI with a random hand,
  with tips that pop up the first time something new happens. ("Practice
  game with tips" on the menu goes straight there.)

  Otherwise pick a format:
    - Starter Kits: Red-White or Blue-Black, 60 cards, 20 life.
    - Commander: one of the four Final Fantasy Commander precons (Limit
      Break, Revival Trance, Counter Blitz, Scions & Spellcraft), 100 cards,
      40 life. Under "Your commander" pick which card leads it: the
      printed commander or the deck's other legend in all of its colors
      (a commander's colors must cover every card in the deck).
      Your commander is the card next to your name: click it to
      cast it when it glows. Each time it's cast from there it costs {2}
      more. When it dies or is exiled (or bounced), you choose whether it
      goes back to the command zone. 21 combat damage from one commander knocks a player out. Many
      precon cards are still "not built yet" (see docs/commander.md).
  Then choose how many AI opponents (1-3), and press Start game.

  How to play:
    - Glowing cards in your hand are playable. Click one to play it, then
      pay for it: your lands and other mana sources glow blue; click them to
      tap them for mana (a land that makes several colors asks which). It
      is cast as soon as the mana is there. Auto-pay taps for you, and
      "Tap mana automatically" in Settings (the gear on the board) does that every time.
    - When a card's ability triggers, the card appears large in the middle
      of the table for 2 seconds and in the card viewer on the right.
    - If a spell or ability needs a target, the legal targets glow gold.
      Click one.
    - Attacking: click your creatures to choose attackers (with several
      opponents, click an opponent first to choose who to attack), then
      press Attack.
    - Blocking: click an attacking creature, then the creature that blocks
      it. Then press Confirm blocks.
    - The button on the right of the prompt bar passes priority or moves
      to the next step ("Go to combat", "End turn", "Let it resolve").
    - Hover over any card to see it large, with its rules text, on the right.
    - Turns pass automatically when you have nothing to do. Tick "Stop at
      every step" in Settings (the gear on the board) to stop everywhere.

  THE DECKS: the exact Final Fantasy Starter Kits
    Every game uses the two real 60-card Final Fantasy Starter Kit decks,
    and every card works as printed.

  More things you can do:
    - Click a permanent to use its abilities: equip an Equipment, or tap
      Coeurl. If a card can do several things (Cloudbound Moogle can be
      cast or Plainscycled), buttons in the prompt bar let you choose.
    - Modal spells (Suplex) ask you to choose a mode first.
    - Cards you can cast from your graveyard (flashback) or exile (Lightning)
      appear next to your hand with a purple "from graveyard"/"from exile" tag.
    - Next to each battlefield are that player's library, graveyard and
      exile. Click a graveyard or exile pile to look through it.
    - Snarl lands (like Furycalm Snarl) ask whether to reveal a matching
      land to play them untapped, or play them tapped.
    - Surveil shows you the top card of your library: keep it or put it into
      your graveyard.
    - Small badges on cards: green +N = +1/+1 counters, the box in the corner
      = current power/toughness (green when changed), red = damage.

  Card images come from Scryfall, so you need an internet connection to see
  them. Offline, cards are drawn as simple frames instead.


3. PLAY IN THE TERMINAL
-----------------------
  npm run play

  You play the red-white deck against one AI opponent. Options:

    npm run play -- --deck UB              play the blue-black deck instead
    npm run play -- --opponents 3          a 4-player pod (you + 3 AIs)
    npm run play -- --seed 42              a specific shuffle (replayable)
    npm run play -- --bot random           an opponent that plays randomly

  (Note the extra "--" before the options; npm needs it.)

  Type an option's number and press Enter; press Enter alone to pass.
  b = show the board, f = stop at every step, ? = help, q = concede.


4. WATCH THE BOTS PLAY
----------------------
  npm run sim                                 2 AIs, seed 1, full game log
  npm run sim -- --players 4 --seed 7         a 4-player pod
  npm run sim -- --players 3 --quiet          only the result


5. RUN THE TESTS
----------------
  npm test              all automated tests (about 20 seconds)
  npm run typecheck     TypeScript type checking
  npm run check         both of the above
  npm run fuzz          10,000 random bot games checking for rule bugs
                        ("npm run fuzz -- --games 300" is much quicker)

  Every test should pass. If one fails, the output names the test and what
  went wrong.


6. UPDATING CARD DATA FROM SCRYFALL
-----------------------------------
  npm run scryfall

  Saves image links and rules text for any card not saved yet. Scryfall
  limits how often its API can be called, so the game itself never calls
  it; only this command does, in as few requests as possible. Use
  "npm run scryfall -- --refresh" to fetch everything again.


7. WHERE THINGS ARE
-------------------
  packages/client   the browser game board
  packages/engine   the rules engine (turns, stack, combat, triggers)
  packages/cards    card definitions and the Starter Kit decklists
  packages/bots     the AI, the terminal game, the simulator, the fuzzer
  docs/             development log (development-update.md), roadmap
                    (starter-kits.md) and decisions (decisions.md)
